# S3XY Dash Mount

### Intro

This is a alternative way to mount the S3XY Dash from Enhance behind the sreeringwheel.
I designed it for my Model 3 Facelift (2021-2022),
but it should also be compatible with the Prefacelift Model 3 (2017-2020)
and the Model Y Prejuniper (2021-2023).

This mount clips into the air vent behind the trim and dose not need to be glued or tapeded to it.
The Mount with its brackets should fit centerd behind the steeringwheel.

The brackets and the Mount itself have slotted holes, so it can be acjustet in position forward, backward and also a bit up and down.
In my case i am also able to see the S3XY Strip above the S3XY Dash.

### Prerequisites
- The original S3XY Dash Mount. We need the magnetic plate and the screw + nut from it.
- a 3D Printer and Material that withstands >70°C.
> I can tell, PETG is a bad choice. ;-)
> PC (PolyCarbonate) works well.
- 2x 10cm self-adhesive foam rupper strip, 3mm thick, 3mm - 13mm wide
- Screws:
 - 4x M3x12mm cylinder head hex socket
 - 4x M3 flap disk
 - 4x M3 washer
 - 4x M3 spring washer
 - 4x M3 nut
 - 2x M5 flap washer
